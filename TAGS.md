# Blog Tags

Repo-only reference (not published) for `tags:` in `src/content/writing/**`.

- `transformers`: Transformer models and attention mechanisms.
- `architectures`: new neural architectures or architectural mechanisms.
- `inductive biases`: structure built into a model to shape what it learns.
- `relational reasoning`: learning and reasoning about relations between objects.
- `generalization`: out-of-distribution, length, and data-efficient generalization.
- `reasoning`: multi-step and algorithmic reasoning, including chain-of-thought.
- `language models`: work on or with (large) language models.
- `learning theory`: theoretical analysis of learning: sample complexity, approximation, convergence.
- `reinforcement learning`: sequential decision-making and multi-agent learning.
