# Components

This directory contains reusable UI components for article content, graph views,
site layout, and publication lists.

Ownership: template-owned. Downstream sites should usually customize behavior
through config, content, and data rather than editing components directly.

Subdirectories group components by surface: `article/`, `graph/`, `layout/`, and
`publications/`.

See [Repo Ownership](../../docs/repo-ownership.md) for the full policy.
