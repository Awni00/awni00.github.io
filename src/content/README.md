# Content

This directory contains conventional page content and the graph-structured
writing corpus for a downstream website.

Ownership: site-owned. Edit `pages/` for standalone pages and `writing/` for
writing-map entries.

Do not add ordinary README files inside `pages/`, `writing/`, or nested writing
folders unless the content loader is updated to exclude them; Markdown files
there can become Astro content entries.

See [Repo Ownership](../../docs/repo-ownership.md) for the full policy.
